Fibrowser
A Fibonacci-powered visual file system browser for power users
Problem Statement
Standard file managers lack intuitive visual hierarchy for deeply nested directories. Power users waste time navigating to locate files — especially when managing project folders with dozens of sub-directories. Fibrowser reimagines file navigation as a structured visual experience.
Key Features
  • Fibonacci-based recursive directory traversal for visually weighted hierarchy
  • Persistent filter & search across entire file tree with real-time updates
  • Custom PyQt5 interface with keyboard navigation and context menus
  • File metadata panel showing size, modified date, and path breadcrumbs

AI / CV 3D Web
MindMusic
Gesture-driven 3D music experience powered by computer vision
Problem Statement
Traditional music interfaces require physical controllers or keyboards, excluding users with motor disabilities and limiting expressive interaction. MindMusic creates a touchless, immersive music experience driven entirely by hand gestures in real-time — no hardware required.
Key Features
  • Real-time 21-keypoint hand tracking via MediaPipe at 30fps in-browser
  • 3D particle universe rendered with Three.js that reacts to gesture amplitude
  • Gesture-to-note mapping: pinch = pitch, open palm = reverb, swipe = rhythm change
  • Web Audio API synthesis engine with customisable instrument profiles
